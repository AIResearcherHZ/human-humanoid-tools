# 电机密度统一 3.1 重生成踩坑记录

## 背景

把三种电机（RP40S行星关节模组_A01 2026.03.24 v2、RP70H外形图 V1.0 20260310 v1、RP50H(厚度59.5) v1）的密度统一改成 3.1，其余零件（抱箍、固定件等）恢复原始密度，然后重新生成质心/惯量 → links.json → URDF/MJCF。

原始密度参照 `s5激进单边骨架_materials_原来的.json`：
- RP40S 原始 ≈ 2.9983
- RP70H 原始 ≈ 3.5013
- RP50H 原始 = 7.85
- 抱箍等 = 2.7

## 踩坑点

### 1. 镜像件名称带 `(镜像)` 后缀，匹配时漏掉 → 左右臂不对称

最初脚本只用 `{'RP40S行星关节模组_A01 2026.03.24 v2','RP70H外形图 V1.0 20260310 v1','RP50H(厚度59.5) v1'}` 这三个 base name 去匹配，结果：
- `RP50H(厚度59.5) v1(镜像)` 没匹配到，仍是 7.85
- `RP40S行星关节模组_A01 2026.03.24 v2(镜像)` 没匹配到，仍是 2.9983

**后果**：左臂（镜像）的 shoulder_pitch_link mass=1.249kg，右臂只有 0.558kg，左右严重不对称。

**修复**：匹配时同时判断 `name in base_names` 或 `name.endswith('(镜像)') and name[:-len('(镜像)')] in base_names`。20 个电机件（含镜像）全部改为 3.1 后左右臂完全对称（均 0.558kg）。

### 2. 密度改了只缩放 mass 和 inertia，com 不变

materials JSON 的 `com_mm` 是质心位置，与密度无关；`mass_kg` 和 `inertia_kg_m2` 随密度线性缩放（ratio = 新密度/旧密度）。验证：`mass_ratio == density_ratio`，`inertia 各分量 ratio == density_ratio`，`com_mm` 前后完全一致。

### 3. 验证脚本 STAGE3 备份目录已不存在 → 改用 STAGE4

`validate_generated.py` 里 `STAGE3 = .../备份/Semi_Taks_LV1_STAGE3`，该目录已被删，验证直接 `FileNotFoundError`。改成 `Semi_Taks_LV1_STAGE4` 后，link/joint 结构对比完全一致，验证通过。

### 4. 腰部闭链跟踪误差对臂部质量敏感

RP50H 密度从 7.85 降到 3.1 让臂部变轻。若镜像件漏改（坑1），waist_roll_link 上的负载不对称，腰部 PD 跟踪误差会超 0.015 阈值（0.0201）。镜像件全改对后误差降到 0.0105，PASS。说明这步验证能抓住质量分布不对称的问题。

## 正确流程

1. 以 `s5激进单边骨架_materials_原来的.json` 为基底 deepcopy
2. 对 base name 或 base name + `(镜像)` 的电机件，`density=3.1`，`mass *= 3.1/旧密度`，`inertia 各分量 *= 3.1/旧密度`，`com_mm` 不动
3. 其余所有零件保持原值
4. 写回 `s5激进单边骨架_materials.json`
5. 跑 `step_export_links.py` → 重新生成 `links.json`（质量守恒检查通过）
6. 跑 `build_urdf_mjcf.py` → 重新生成 `Semi_Taks_LV1.urdf` / `Semi_Taks_LV1.xml`
7. 跑 `validate_generated.py`（参照 STAGE4）→ `status: PASS`

- 闭链跟踪误差 0.0022
